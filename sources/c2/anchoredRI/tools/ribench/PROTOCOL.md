# Task C: RIbench evaluation

Use CRAN RIbench 1.0.2 and its unchanged test-set definitions and generation sequence. First fit the 2,880 rows with N <= 5,000. Do not fit N=50,000 or 500,000 until the first stage's runtime has been reported. Generation internally advances the full sequence even for a subset, preserving benchmark data hashes.

For each row, read Data/<Analyte>/<Index>_<Analyte>_seed_<startSeed>.csv, column V1, and validate the RIbench hash. Draw exactly 40 independent reference observations using seed startSeed + 17000000, inverse Box–Cox of rnorm(40, nonp_mu, nonp_sigma), then add nonp_shift. Remove negative/nonfinite draws and round to decimals. Do not replenish removed draws; record surviving sample size. The supplied seed rule reuses anchors for rows with the same distribution parameters and startSeed. These comparisons are dependent across such rows.

Fit the one-group anchored mixture with automatic identity/log/shifted-log selection and 1–3 components. Generalize the existing setting dimensions and BIC parameter counts to one group; retain two-group numerical behavior. Fit the Task A automatic anchors-only estimator, with its sample-size guard relaxed only if fewer than 40 draws survive. Neither fitting method receives the generating parameters. Those parameters are used only to simulate anchors. Both anchored methods receive additional screened observations that refineR does not receive; describe this as an augmented-data comparison.

Run a trivial percentile wrapper through evaluateBiomarkerTestSets(requirePercentiles=TRUE) on one benchmark dataset and inspect its saved object before saving custom results. Match that format exactly. RIbench requests 2.5th and 97.5th percentiles except CRP, for which it requests only the 95th percentile. For anchorsOnly, keep Task A's 1.96 sample-SD limits for two-sided intervals; use qnorm(.95) for CRP. AnchoredRI uses its fitted Gaussian component quantiles on its selected scale. Errors produce missing estimates and a separate error log; do not substitute anchors-only estimates for anchoredRI failures.

Run refineR through RIbench's normal evaluateBiomarkerTestSets path with its default findRI configuration. Score all three methods with evaluateAlgorithmResults, explicitly restricting to the completed small-N subset. Report its subset scores as subset scores, not the full published benchmark score. Report lambda=0.432 (FT4) separately, and retain per-analyte results, missing-fit counts, and timings. Save exact native Rdata results, custom fit diagnostics, software versions, and source provenance.

The Step B disagreement gate is not applied in this comparison. No tuning of transformations, starts, selection criteria or thresholds based on RIbench results. Changes to R/ in this task are restricted to the explicitly requested one-group support. tools/stress-design.R remains unchanged.

Compatibility note before fitting: R 4.5.0 and data.table 1.16.4 are used. Several fread versions retain a growable-vector flag that changes serialized hashes without changing values. reader-compat.R copies numeric columns through +0L, asserts identical values and integer/double type, and is supplied via RIbench's sourceFiles argument. All 2,880 generated small-N vectors were verified against the original RIbench hashes after this copy. Hash validation is never disabled or replaced; no CSV measurements or test-set definitions are changed.

## C2: design error discovered after the initial run
The original startSeed + 17000000 rule reused one anchor sample per analyte, only ten samples across 2,880 test sets. This was a design error found after the run, not a tuning change. Correct the seed to 17000000 + Index. Before any fits, verify that all 2,880 final rounded anchor vectors are distinct. Refit only anchoredRI and anchorsOnly; retain the existing refineR Rdata files byte-for-byte. All estimator, transformation, rounding and scoring settings remain unchanged.
Save the Step B fixed-transformation, fixed-offset, 2-df anchor likelihood-ratio statistic and nominal p-value as diagnostics only. Do not decline intervals. Report the same metrics and FT4 subset, plus paired mean differences and wins against anchorsOnly and refineR by distribution type and pathological fraction <=20% versus >20%. List every dataset with either endpoint absolute Z deviation >5, with method, analyte, pathological fraction, transform, components and available bound diagnostics. Do not invent diagnostics absent from saved refineR models. No large-N datasets may be started until user review.
