# Archived RIbench N = 50,000 inputs

The C2 workflow fit refineR 2.0.0, the original anchoredRI fitter, and the anchors-only estimator on 1,440 distinct RIbench test sets. The preserved ZIP matches the SHA-256 digest GitHub supplied for artifact 14786706939. It contains the original fit outputs, historical performance tables and anchor hashes for all three methods. [Original run](https://github.com/amromeo/amromeo.github.io/actions/runs/45101564181)

The fit source commit was `f3cc3d36edb0393bf7c66f1cafc43cc12fe8e425`. The source directory contains the relevant run, scoring and anchor scripts. The archive preserves per-shard source manifests and session records. The published tables were located at commit `b98c345a3faacaa38666af77035a6b88c5df8639`.

`testsets.csv` contains the original decimal literals from RIbench 1.0.2’s SpecificationTestSets.csv restricted to N = 50,000. The RIbench definition supplies Index, generator seeds, rounded routine-vector HashCode, analyte rounding precision and truth. `members.csv` identifies and hashes all 4,320 method-specific raw outputs. `model-inventory.csv` lists the 1,440 refineR model member paths and SHA-256 digests. `anchor-sample-hashes.csv` is byte-for-byte the archived CSV.

Native R readback confirmed all four parameters in all 1,440 model objects agree with the corresponding full-precision refineR performance RDS. Every model records version 2.0.0, BoxCox, no bootstrap and ResultFound. Every sigma is positive, every shift is zero, and fitted lambda ranges from zero through one. All 1,440 reproduced anchor vectors have 40 observations and match their archived hashes. This inspection verified the inputs before Stage 1 testing.

The original workflow verified every rounded routine-vector HashCode before fitting, then archived only the results. To independently reproduce these inputs, run the frozen `verify-routines.R` after the small cohort. RIbench 1.0.2 traverses the full simulation sequence in each original shard, saving a CSV only when the Index belongs to the shard. Each of the 60 shards started with Hb and seed 123. One traversal with their union therefore reproduces the same draws and individual files. The script checks the initial conditions and partition, validates all original vector hashes after the archived reader, and writes new per-Index SHA-256 hashes.
