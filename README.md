# anchorRefine

A planned GPL-3 derivative of refineR 2.0.0 that uses screened healthy anchors while fitting the healthy distribution in routine data. This project is separate from anchoredRI.

anchorRefine is derived from refineR 2.0.0. It is an independent project and is not endorsed by the refineR authors. Upstream authors: Matthias Beck, Tatjana Ammer, Christopher M Rank, and Andre Schuetzenmeister. Upstream notices and source will be preserved when vendored after protocol review.

Current state: documentation only. Read [PROTOCOL.md](PROTOCOL.md) for stages 0–1, stage gates, and plans for stages 2–3. No algorithm code or benchmark runs have been created.
